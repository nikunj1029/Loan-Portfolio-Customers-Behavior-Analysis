# Loan-Portfolio-Customers-Behavior-Analysis

OverView 
Developed a multi-page Power BI dashboard integrated with SQL to analyze loan performance, customer risk, and approval opportunities. The project focuses on identifying high-risk customers, improving loan approval decisions, and supporting data-driven financial strategies.
⸻
🔴 Banks often face challenges in:
	•	Identifying high-risk customers before loan approval
	•	Understanding default patterns and financial stress
	•	Making data-driven loan approval decisions
	•	Balancing revenue growth with risk control
This project aims to solve these problems using data analysis and business-driven metrics.
⸻
🛠️ SQL Work
	•	Cleaned and structured raw banking datasets
	•	Performed joins between customers, loans, and transactions
	•	Created views for:
	•	Loan summary
	•	Customer activity
	•	Default analysis
	•	Used aggregations and filtering to prepare data for reporting
	•	Ensured data consistency before loading into Power BI
⸻
📈 Analysis (Power BI)
	•	Customer segmentation based on risk, income, and EMI ratio
	•	Identified high-risk and default customers
	•	Calculated loan approval eligibility using rule-based logic
	•	Analyzed:
	•	Loan distribution
	•	Default trends
	•	Customer activity (active vs inactive)
	•	Revenue (interest earned)
	•	Built 5-page dashboard covering:
	•	Overview
	•	Risk Analysis
	•	Customer Segmentation
	•	Transaction Behavior
	•	Performance Insights
⸻
 Business Solutions
	•	Enabled early identification of high-risk customers, reducing potential losses
	•	Helped bank design targeted loan approval strategies
	•	Improved decision-making using EMI ratio and income-based evaluation
	•	Provided visibility into default impact and risk exposure
	•	Supported revenue optimization by focusing on safe loan segments
⸻
⚙️ Tools & Technologies
	•	Power BI → Dashboard & Data Visualization
	•	SQL (MySQL) → Data Cleaning, Joins, Views
	•	Excel / CSV → Data Source
	•	DAX → KPI calculations and business logic
